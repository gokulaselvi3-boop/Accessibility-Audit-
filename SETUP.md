# Setup Guide

## Prerequisites

- GitHub account
- Google Chrome
- Chrome DevTools
- Lighthouse

## Accessibility Testing

1. Open the target website in Google Chrome.
2. Open Chrome DevTools.
3. Select Lighthouse.
4. Select Accessibility.
5. Run the Lighthouse audit.
6. Save the Lighthouse screenshot.
7. Test the website using keyboard navigation.
8. Record five actual accessibility issues.
9. Capture evidence screenshots.
10. Add the findings to `AUDIT_REPORT.md`.

## Verification

- Lighthouse testing completed
- Keyboard testing completed
- Five accessibility issues documented
- Evidence screenshots added
- WCAG criteria recorded
- Remediation steps documented

## Security

Do not upload passwords, API keys, tokens, or private information.
